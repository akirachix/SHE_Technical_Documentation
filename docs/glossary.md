<div class="backend-page-header">
  <h1>Glossary</h1>
  <p>Common technical and domain terms used across this documentation.</p>
</div>


<div class="backend-card product-domain-terms">
  <h2><span class="twemoji"></span> Product &amp; Domain Terms</h2>
  <ul class="card-feature-list">
    <li><strong>Player</strong> — A user who plays digital-safety games and can ask for help if they feel unsafe.</li>
    <li><strong>Administrator</strong> — A user who manages content, checks AI-made games, and looks after the platform.</li>
    <li><strong>Support Provider</strong> — A trusted group or person that receives and answers help requests from players.</li>
    <li><strong>Game Progress</strong> — A saved record of a player's run through a game, including their score and if they finished it.</li>
  </ul>
</div>


<div class="backend-card security-auth-terms">
  <h2><span class="twemoji"></span> Security &amp; Login Terms</h2>
  <ul class="card-feature-list">
    <li><strong>MFA</strong> — Multi-Factor Authentication; a two-step login system that needs a code after your password for extra safety.</li>
    <li><strong>TOTP</strong> — Time-based One-Time Password; a temporary security code from an authenticator app.</li>
    <li><strong>OTP</strong> — One-Time Password; a single-use safety code sent via email.</li>
    <li><strong>JWT</strong> — JSON Web Token; a secure, digital key given after login to keep your account signed in safely.</li>
  </ul>
</div>


<div class="backend-card ai-generation-terms">
  <h2><span class="twemoji"></span> AI &amp; Game Generation Terms</h2>
  <ul class="card-feature-list">
    <li><strong>AI</strong> — Artificial Intelligence; computer systems built to perform smart tasks like a human.</li>
    <li><strong>Gemini</strong> — Google's smart AI service used to automatically build game text and questions.</li>
    <li><strong>Grounding</strong> — Forcing the AI to build games using only the files you uploaded, so it does not make things up.</li>
    <li><strong>File Search</strong> — The way the Gemini AI searches through your uploaded documents to find facts for a game.</li>
    <li><strong>Human-in-the-loop</strong> — A workflow where a real person (Admin) must check and approve an AI game before players see it.</li>
    <li><strong>Payload</strong> — The final package of organized JSON data containing a game's full text, quizzes, and scenarios.</li>
  </ul>
</div>


<div class="backend-card tech-stack-terms">
  <h2><span class="twemoji"></span> Core Tech Stack Frameworks</h2>
  <ul class="card-feature-list">
    <li><strong>FastAPI</strong> — The fast Python code framework used to build our web API communication engine.</li>
    <li><strong>PostgreSQL</strong> — The organized storage system (relational database) used to save platform data securely.</li>
    <li><strong>ORM</strong> — Object-Relational Mapping; a helper (SQLAlchemy) that lets our Python code talk to the database easily.</li>
  </ul>
</div>


<div class="backend-card general-web-terms">
  <h2><span class="twemoji"></span> General Web &amp; Testing Terms</h2>
  <ul class="card-feature-list">
    <li><strong>API</strong> — Application Programming Interface; a digital bridge that lets apps talk to each other.</li>
    <li><strong>REST</strong> — The standard, clean design style used to structure our API web paths.</li>
    <li><strong>JSON</strong> — A simple text format used to send and receive structured data through the API.</li>
    <li><strong>ERD</strong> — Entity Relationship Diagram; a visual blueprint map showing our database tables and how they link.</li>
    <li><strong>E2E</strong> — End-to-end testing; checking a complete user journey from start to finish to ensure it works.</li>
    <li><strong>CORS</strong> — Cross-Origin Resource Sharing; safety settings that control which frontend apps can call your backend.</li>
    <li><strong>CI/CD</strong> — Automated computer tasks that build, test, and deploy code changes to servers automatically.</li>
  </ul>
</div>
